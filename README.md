# 멍냥이의 버스여행 🚌🐱🐶

시골 버스 정류장 분위기의 컬러 매칭 주차 퍼즐 웹게임.

▶ 플레이: https://a-peaches.github.io/busGame/

- 주차장에서 앞이 뚫린 버스를 눌러 대기 칸으로 보내요. 상하좌우와 대각선, 8방향이 있어요.
- 하트 모양 길을 도는 고양이·강아지 승객은 같은 색 버스에 걸어가서 타요.
- 대기 칸이 꽉 찼는데 아무도 탈 수 없으면 실패예요.
- 100단계까지 있고, 10단계마다 난이도가 쉬움 → 어려움 → 매우 어려움으로 반복돼요. 별 5개(최고 난이도)는 30단계마다 나와요.
- 31단계부터는 레일 버스 이벤트가 나와요. 버스를 누를 때마다 레일이 한 칸씩 움직이고, 노란 출구 칸에 온 버스만 출발할 수 있어요.

## 실행

```powershell
python -m http.server 8080
```

브라우저에서 http://localhost:8080 을 열어요.

테스트용 주소: `?level=10`(그 단계로 바로), `?season=winter`, `?hour=19.5`, `?weather=snow`, `?test`(닉네임·위치 묻지 않기)

## 파일 구조

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 뼈대 |
| `css/style.css` | 화면 꾸미기 |
| `js/config.js` | 색, 상수, 저장소, 아이콘, 공용 도구 |
| `js/level.js` | 도형 계산, 단계 만들기(난이도·레일 버스), 게임 시작 |
| `js/game.js` | 게임 화면 배치, 터치 입력, 매 프레임 업데이트 |
| `js/draw.js` | 버스, 멍냥이, 정류장, 주차장, 레일 그리기 |
| `js/ui.js` | 단계 지도, 팝업, 축하·실패 연출 |
| `js/scene.js` | 계절 풍경, 수채화 나무, 메인 화면의 움직이는 버스 |
| `js/world.js` | 실시간 하늘, 날씨, 하트, 닉네임, 설정 창 |
| `js/audio.js` | 피아노 합성 배경음악과 효과음 |
| `js/main.js` | 시작 |

스크립트는 위 순서대로 불러와요. 파일을 고친 뒤 배포할 때는 `index.html`의 `?v=` 번호를 올려야 폰에서 바로 새 버전이 보여요.
