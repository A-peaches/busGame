# 버스 출발! 🚌

시골 버스 정류장 분위기의 컬러 매칭 주차 퍼즐 웹게임.

- 주차장에서 앞이 뚫린 버스를 눌러 대기 칸으로 보내요. 상하좌우와 대각선, 8방향이 있어요.
- 빙글빙글 도는 원 위의 고양이·강아지 승객은 같은 색 버스에 탈 수 있어요.
- 대기 칸이 꽉 찼는데 아무도 탈 수 없으면 실패예요.
- 단계가 오를수록 버스와 색이 많아지고, ❓ 미스터리 버스가 나와요.

## 실행

```powershell
python -m http.server 8080
```

브라우저에서 http://localhost:8080 을 열어요. 주소 끝에 `?level=10`을 붙이면 원하는 단계로 바로 갈 수 있어요.
